# Кастомные страницы наборов Омега-3

Кастомный шаблон включается только для slug из:

```text
constants/omegaBundles.ts
```

Этот же массив задаёт товары недели и их порядок в каталоге.

## Источник данных

Товар не создаётся на фронтенде. `product_id`, название, цена, галерея и
варианты всегда берутся из реального ответа:

```http
GET /v1/shop/products/{slug}/card
```

Минимальная структура варианта:

```json
{
  "variant_id": "<uuid варианта>",
  "label": "1x Омега-3 + 1x Dermic",
  "price": 36500,
  "is_default": true,
  "sort_order": 0,
  "items": [
    {
      "component_product_id": "<uuid компонента>",
      "quantity": 1
    }
  ]
}
```

Если `variants` не пришёл, фронтенд не создаёт временные варианты и блокирует
добавление товара в корзину.

Локально хранятся только тексты и изображения дополнительных маркетинговых
блоков кастомной страницы:

```text
data/omegaBundlePageContent.ts
```

## Добавление в корзину

Для выбранного серверного варианта в обычный запрос корзины добавляется
`variant_id`:

```http
POST /v1/shop/cart/{daigoID}
Content-Type: application/json
```

```json
{
  "product_id": "<product_id из карточки>",
  "variant_id": "<variant_id выбранного варианта>",
  "quantity": 1
}
```

Для гостя используется такое же тело:

```http
POST /v1/shop/guest-cart/{sessionId}
```

Для обычных товаров без вариантов поле `variant_id` не отправляется.
