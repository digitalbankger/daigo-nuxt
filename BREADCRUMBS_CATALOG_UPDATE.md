# Изменения каталога и хлебных крошек

- На SEO-ЧПУ каталога H1 теперь соответствует выбранному SEO-фильтру, например `/catalog/kishechnik-i-immunitet` → `Кишечник и иммунитет`.
- На главной блок «Выбор продуктов по направлениям» ведёт сразу на ЧПУ `/catalog/<slug>`, без `?napravlennost=`.
- На страницах основного layout добавлены видимые хлебные крошки, кроме главной.
- Страницы, где уже были собственные хлебные крошки (товар, статья, исследование, каталог), используют свои точные данные без дублей.
- Для статей и исследований добавлен fallback хлебных крошек, если поле `breadcrumbs` отсутствует в данных.
- Исправлен домен в BreadcrumbList исследований: `daigo.ru` вместо `example.com`.
- На каталог добавлена цепочка `Главная → Каталог → SEO-раздел`, и такая же структура используется в BreadcrumbList JSON-LD.
- Изолированная `/catalog/5ml-test` не менялась: это noindex-страница в отдельном layout, чтобы не ломать её изолированный дизайн.
